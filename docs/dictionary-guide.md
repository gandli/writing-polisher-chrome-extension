# 词典制作指南

本文档介绍如何制作和维护转换词典，适合初始整理和日常维护。

## 词典格式

词典是一个标准的 JSON 文件，格式非常简单：

```json
{
  "口语表达": "专业表达",
  "另一个口语表达": "另一个专业表达",
  "长一点的口语短句": "对应的专业表达"
}
```

- **Key**：需要匹配的口语化表达（大小写敏感吗？目前是精确匹配，区分大小写，后续可以加选项）
- **Value**：建议替换的专业书面表达

## 制作方式

### 方式一：初始批量制作

#### 1. 人工整理（适合少量词条）

1. 打开 `src/data/dictionary.json` 文件
2. 按照上面的格式添加词条，每个词条占一行
3. 保存文件，重新加载扩展就可以使用了

#### 2. Excel 整理后转 JSON（适合批量录入）

1. 在 Excel 中新建两列：
   - A 列：口语表达
   - B 列：专业表达
2. 保存为 CSV 文件
3. 使用下面的 Python 脚本转换为 JSON：

```python
import csv
import json

csv_file = 'dictionary.csv'
json_file = 'dictionary.json'

data = {}
with open(csv_file, 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        if len(row) >= 2:
            colloquial = row[0].strip()
            formal = row[1].strip()
            if colloquial:
                data[colloquial] = formal

with open(json_file, 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

print(f"转换完成，共 {len(data)} 个词条")
```

4. 将生成的 `dictionary.json` 替换到 `src/data/dictionary.json`

#### 3. LLM 辅助整理（适合大批量快速生成）

⚠️ **重要提醒：保密安全第一**
- 如果数据在内网，必须使用内网本地部署的 LLM 处理
- 如果要拿到外网处理，必须先做**完整脱敏**，删除所有真实案件信息（姓名、地址、案号、金额等），只保留表达模式

**步骤：**

1. 准备一些已经规范好的文书文本
2. 使用下面的 Prompt 让 LLM 帮你提取口语→专业对应关系：

```
你是一个法律文书表达整理助手。
请帮我从下面的规范法律文本中，找出常见的口语化表达方式，并给出对应的专业表达。

输出要求：
1. 只输出 JSON 格式，不要其他任何内容
2. 格式：{"口语表达": "专业表达", ...}
3. 只整理那些口语和书面差异明显的表达，差异不大的不需要整理

文本：
---
[这里粘贴你的文本]
---
```

3. LLM 输出后，人工校验一遍，删除错误匹配
4. 保存为 JSON 文件放入项目

### 方式二：日常使用中积累

在扩展使用过程中，可以直接在扩展选项页面添加新词：

1. 点击浏览器扩展图标 → 点击「打开选项页」
2. 在「词典管理」→「新增词条」
3. 输入口语表达和专业表达，点击「保存」
4. 立即生效，不需要重启浏览器

## 匹配规则

- **长句优先**：词典中同时有"抓到"和"当场抓到"，会优先匹配"当场抓到"，避免拆分
- **精确匹配**：完全匹配文本内容
- **支持任意长度**：单个词到多个句子都支持

## 最佳实践

1. **先常用后生僻**：先整理你们团队最常用的口语化表达，再慢慢补充
2. **覆盖完整**：同一个意思不同口语说法，可以都加上，指向同一个专业表达：
   ```json
   "扣了": "依法扣押",
   "扣走": "依法扣押",
   "拿走": "依法扣押"
   ```
3. **定期汇总**：积累一段时间后，导出词典，汇总到内置词典中，方便新用户使用
4. **团队共享**：通过导出/导入功能，团队成员可以共享整理好的词典，一起积累

## 词典导入导出

- **导出**：在选项页点击「导出词典」，会下载一个 JSON 文件，保存好可以分享给同事
- **导入**：在选项页点击「导入词典」，选择 JSON 文件，会合并到你的词典中（重复词条会覆盖）

## 注意事项

1. **JSON 格式正确性**：添加词条后要保证 JSON 格式正确，最后一个词条后面不要加逗号
2. **特殊字符**：如果表达中包含双引号 `"`，需要转义写成 `\"`
3. **保密**：不要在词典中放入任何真实案件信息，只放表达转换规则
