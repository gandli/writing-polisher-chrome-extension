# 法条整理指南

本文档介绍如何整理和维护法条库，扩展会自动识别文本中的法条引用并支持点击查看内容。

## 法条格式

法条使用 JSON 格式存储：

```json
{
  "法律名称": {
    "条款号": "条款内容",
    "另一个条款号": "另一个条款内容"
  },
  "中华人民共和国烟草专卖法": {
    "第一条": "为实行烟草专卖管理，有计划地组织烟草专卖品的生产和经营，提高烟草制品质量，维护消费者利益，保证国家财政收入，制定本法。",
    "第三十一条": "无烟草专卖批发企业许可证经营烟草制品批发业务的，由烟草专卖行政主管部门责令关闭或者停止经营烟草制品批发业务，没收违法所得，并处罚款。"
  }
}
```

- **一级 Key**：法律名称（如"中华人民共和国烟草专卖法"，也可简写为"烟草专卖法"）
- **二级 Key**：条款号（数字即可，不需要加"第"和"条"）
- **Value**：完整的条款内容

## 整理方式

### 方式一：批量整理入内置库

1. 收集你需要的常用法条
2. 按照上面的格式整理成 JSON
3. 保存到 `src/data/laws.json`
4. 重新打包扩展即可使用

### 方式二：扩展页面添加

在扩展选项页面可以直接添加法条：

1. 打开选项页 → 切换到「法条管理」
2. 输入法律名称、条款号、条款内容
3. 点击「添加」即可生效

### 方式三：导出导入

和词典一样，支持导出全部法条为 JSON 文件，也可以导入同事分享的法条库：

- 导出：选项页 →「导出法条」
- 导入：选项页 →「导入法条」

## 识别规则

扩展会自动识别以下格式的法条引用：

| 格式 | 示例 | 识别结果 |
|------|------|----------|
| 《法律名称》第N条 | 《烟草专卖法》第三十一条 | 法律=烟草专卖法，条款=31 |
| 《法律名称》第N款 | ... | 识别对应条款 |
| 法律名称第N条 | 烟草专卖法第三十一条 | 同样可以识别 |

识别会模糊匹配法律名称，不用严格匹配全称，方便使用。

## 最佳实践

1. **常用优先**：先整理你们办案最常用到的法条，不常用的可以后续慢慢加
2. **多个名称**：如果法条有常用简称，可以在 JSON 中添加别名指向同一个内容（或者让用户自己添加）
3. **完整内容**：尽量录入完整的条款原文，保证准确性
4. **定期更新**：法律修订后及时更新条款内容

## 注意事项

1. **准确性**：法条内容一定要准确，建议直接从权威来源复制
2. **格式正确**：保持 JSON 格式正确，否则扩展无法加载
3. **版权**：只录入公开的法律条文，不存在版权问题
4. **保密**：不要添加任何内部保密文件内容，只保留公开法律条文
